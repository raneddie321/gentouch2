# דומינטור | Dominator Gaming — אתר איקומרס ותדמית

קונספט מחודש לאתר רשת הגיימינג דומינטור (חיפה · תל אביב): חנות אונליין מהירה, בעברית מלאה (RTL) ובעיצוב Dark Mode.

## מה יש באתר
- **עמוד בית**: Hero מתחלף (Switch 2, PS5 Pro, מחשבים בהרכבה), גריד קטגוריות, קרוסלת מבצעי השבוע עם טיימר, באנר מעבדת תיקונים, חדשים ובלעדיים, Trust Bar ו-Footer עשיר.
- **Header חכם**: חיפוש עם השלמה אוטומטית (כולל ניווט מקלדת), מגה-תפריט לפי קטגוריות, וואטסאפ, אזור אישי, מועדפים ועגלה נפתחת (Slide-over).
- **קטלוג**: סינון לפי קטגוריה/תת-קטגוריה, מותג, מחיר, מבצעים וזמינות, מיון, ו-Bottom Sheet במובייל. כל הסינונים נשמרים ב-URL.
- **עמוד מוצר**: גלריה, תשלומים, זמינות בסניפים, מפרט, מוצרים דומים, קנייה מהירה.
- **קופה**: משלוח / אקספרס / איסוף מסניף, קופונים (`CREW50`, `DOM10`), ולידציה מלאה. *דמו — לא מתבצע חיוב.*
- **מעבדת תיקונים**: מחירון, קביעת תור אונליין (מכשיר → תקלה → סניף → תאריך → שעה) ומעקב סטטוס לפי מספר כרטיס.
- **סניפים, אזור אישי, מועדון לקוחות, עמודי מידע ו-404.**

הקטלוג (~65 מוצרים) מדומה ומבוסס על סוגי המוצרים שהרשת מוכרת; המחירים להמחשה. תמונות המוצרים הן איורי SVG שנוצרו בקוד — אפשר להחליף בתמונות אמיתיות דרך `src/data/products.ts`.

## לפני עלייה לאוויר
עדכנו את פרטי הקשר האמיתיים ב-`src/data/site.ts`: מספר וואטסאפ, טלפונים, שעות פתיחה וקישורי רשתות חברתיות (כרגע ערכי placeholder).

## הרצה
```bash
npm install
npm run dev      # פיתוח
npm run build    # בנייה ל-dist/
```
מוכן לפריסה ב-Vercel (`vercel.json` כולל rewrites ל-SPA).

**Stack:** React 19 · TypeScript · Vite · Tailwind CSS · React Router · lucide-react
